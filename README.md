 ✅ To-Do List App

A minimal and user-friendly **To-Do List Application** built using **HTML**, **CSS**, and **JavaScript**. This project was created by following a YouTube tutorial and helped reinforce my understanding of DOM manipulation and local storage for data persistence.

---

## 🎮 Demo

You can [click here to use the app](https://todolistapp-github-io.vercel.app/) *(Replace with your live project link)*

---

## 🚀 Features

- Add and delete tasks dynamically  
- Mark tasks as completed  
- Data **does not get lost on refresh** thanks to **localStorage**  
- Clean and intuitive UI  
- Fully responsive design
